# Day 16: Loading and Exploring a CSV Dataset Using Pandas

## Description

This project demonstrates how to create, load, and explore a CSV dataset using Python and the Pandas library. A student performance dataset is used to understand basic data analysis operations.

## Objective

To learn how to load CSV files using Pandas and explore datasets using different functions.

## Tools Used

* Python
* Jupyter Notebook
* Pandas

## Concepts Covered

* Importing the Pandas library
* Creating a DataFrame
* Creating a CSV file using `to_csv()`
* Loading CSV data using `read_csv()`
* Displaying the first and last five rows using `head()` and `tail()`
* Checking dataset dimensions using `shape`
* Displaying column names using `columns`
* Understanding dataset information using `info()`
* Generating summary statistics using `describe()`
* Calculating average, maximum, and minimum marks

## Dataset

The sample dataset contains five students with their names, marks, and grades.

## Analysis Performed

* Counted the total number of students.
* Calculated average marks.
* Identified the highest marks.
* Identified the lowest marks.

## Result

Successfully created and loaded a CSV dataset using Pandas and performed basic data exploration and analysis.

## Conclusion

This task helped me understand how Pandas is used to organize, explore, and analyze structured data. These concepts are useful for my learning journey toward becoming a Data Analyst.
